# Desktop Agent

Десктоп-приложение в духе Codex / Claude Desktop: вы пишете задачу в чат, а агент работает с файлами
и командами на вашем компьютере. Всё, что что-то меняет, выполняется только после вашего «Разрешить».

> Сейчас внутри встроенный **демо-агент** без интернета: он нужен, чтобы проверить приложение.
> Настоящий «мозг» (Notion AI через Agent API) подключается следующим шагом.

## Запуск

Нужен Node.js 22.12+ (или 20.19+).

```bash
npm install
npm run dev
```

Установщик собирается командой `npm run build:win`, `npm run build:mac` или `npm run build:linux`,
результат появится в папке `dist/`.

## Как это работает

1. Вы выбираете рабочую папку: агент видит только её.
2. Приложение отправляет задачу агенту вместе с правилами (`src/main/agent/protocol.ts`).
3. Если агенту нужно действие, он отвечает блоком `<tool>{"name": "...", "args": {...}}</tool>`.
4. Приложение проверяет действие, при необходимости спрашивает вас, выполняет его и отправляет
   агенту результат в блоке `<result>…</result>`.
5. Когда агент отвечает обычным текстом, задача готова.

Инструменты: `list_dir`, `read_file`, `write_file`, `run_command` (PowerShell на Windows, системный
shell на macOS и Linux).

## Безопасность

- Пути за пределами рабочей папки, в том числе через симлинки, отклоняются.
- Чтение файлов и папок выполняется сразу, запись файлов и любые команды — только после подтверждения.
- Явно разрушительные команды (`rm -rf /`, `format C:`, `mkfs`, `shutdown` и т. п.) блокируются без
  вопроса. Это грубая страховка, главная защита — подтверждение.
- У команды лимит 120 секунд, кнопка «Стоп» прерывает её вместе с дочерними процессами.

## Структура

```
src/
  main/        процесс Electron: окно, IPC, хранение чатов
    agent/     протокол, цикл агента, провайдеры («мозги»)
    tools/     инструменты, проверка путей, политика подтверждений
  preload/     мост window.api между интерфейсом и main
  renderer/    интерфейс на React
  shared/      общие типы
```

## Как подключить другой «мозг»

Провайдер реализует `AgentProvider` из `src/main/agent/providers/types.ts`: создаёт сессию, принимает
сообщение и возвращает ответ агента текстом. Пример — `demo.ts`. Новый провайдер добавляется в список
в `providers/index.ts` и появляется в выпадающем списке «Агент».
